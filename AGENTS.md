# AGENTS.md

## Project

This repository contains the public J5 Star Studio website, built with Astro, TypeScript, and CSS and deployed to GitHub Pages.

## Commands

- Install dependencies: `npm install`
- Start local development: `npm run dev`
- Validate and build: `npm run build`
- Preview the production build: `npm run preview`

## Working agreements

- Keep the site fully static and compatible with GitHub Pages at the root path `/`.
- Preserve the Midnight Celestial palette and restrained visual language.
- Use semantic HTML, keyboard-accessible interactions, and `prefers-reduced-motion` support.
- Avoid unnecessary UI libraries and client-side JavaScript.
- Do not publish unapproved game names, internal development documents, private repository details, or other confidential information.
- Do not delete or overwrite unrelated work. Keep changes focused and verify `npm run build` before opening a pull request.
- Never merge directly into `main` without explicit user approval.
